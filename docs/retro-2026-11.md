## Lessons for the next contributor

1. **`App.tsx` is a ~2,000-line god component.** The only working extraction
   pattern is pure functions in `src/lib/*.ts` with zero React imports; inline
   logic (audio graph, seek/draw, export loop) is untestable. Follow the pattern.
2. **Verification is asymmetric.** Pure helpers get tests; risky paths only
   have specs against an *unconfigured* preview, which cannot catch real-backend
   failure. Local green ≠ prod green; prod has been unreachable since Phase 0.
3. **Local-first is the product; cloud features are config, not code.** Cloud
   projects, media sync, share links and analytics all hang on Supabase/Vercel
   settings absent from the repo, currently blocked or unmeasured. Ground
   decisions in 0 stars / 4 downloads / no analytics — MONETIZATION.md's gate
   says so.
