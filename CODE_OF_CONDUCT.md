# Code of Conduct

ClipForge follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. No harassment, personal attacks,
discrimination, or publishing others' private information. Maintainers may
remove content and block offenders.

Report unacceptable behavior by opening a private security advisory on GitHub
(see `SECURITY.md`) or by contacting the maintainers listed in the repository.
We will review reports in good faith, confidentially, and as promptly as
possible — within 7 days for acknowledgement.
