Privacy Policy

Last updated: November 16, 2026

ClipForge is a local-first video editor. The short version: your media never leaves your device unless you explicitly turn on cloud projects and sign in.

What stays on your device

  • Every video, audio and image file you import is processed entirely in your browser. Rendering and exporting happen on your machine.
  • Projects, recent projects, thumbnails and settings are stored in your browser's IndexedDB storage. Clearing browser data deletes them permanently.
  • The desktop app stores the same data on your local disk.

What we never do

  • No advertising, no third-party trackers, no telemetry.
  • No reading of your media files beyond what is required to edit them.
  • No selling or sharing of any personal data, because none is collected.

Optional cloud projects (only if you sign in)

If a deployment enables cloud projects and you choose to create an account and save to the cloud, the following is stored on the deployment operator's Supabase backend:

  • Your email address (for authentication).
  • Project snapshots: edit data such as clip positions, filters, text overlays and markers — JSON, not media.
  • Project media files — uploaded only when the deployment has media sync enabled, and only for projects you save while signed in.
  • A small project thumbnail.

This data is protected by row-level security: authenticated users can only access their own projects. You can delete any cloud project from the dashboard at any time, which removes its stored media too. Deleting your account removes all associated data.

Service providers

  • Vercel hosts the web application. Vercel's own handling of request data is governed by Vercel's privacy policy.
  • Supabase provides the optional cloud storage backend described above, only for deployments that enable it.

Changes
